Modifications
-------------

Hst.Compression.Lha is a modified version of parts of LHa for UNIX with
Autoconf. Modifications by Henrik Nørfjand Stengaard:

- Ported from C to C#. Global state is replaced by classes holding the state.
- Includes sliding dictionary encoder (slide.c), static and dynamic huffman
  encoders (huf.c, dhuf.c, shuf.c), huffman tree and table creation
  (maketree.c, maketbl.c), bit and crc io (bitio.c, crcio.c), header writing
  (header.c) and adding files (lhadd.c, append.c) used to create lha archives.
- Includes -lh2- and -lh3- decoders (dhuf.c, shuf.c, slide.c) used to extract
  lha archives through decoders added to Hst.Compression lha options.
- Archives are created using streams instead of files. Text mode, kanji code
  conversion and symbolic links are not supported when creating archives.
- Added LhaWriter and LhaWriterOptions classes as api for creating archives.

The source code of Hst.Compression.Lha is available at
https://github.com/henrikstengaard/hst-core and is embedded in the symbols of the
package. The source code of LHa for UNIX with Autoconf is available at
https://github.com/jca02266/lha. The original readme of LHa for UNIX with
Autoconf is included in the licenses directory of the source code.
