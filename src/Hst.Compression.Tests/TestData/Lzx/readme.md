# Lzx test data

- `xpk_compress.lzx`: Sample lzx archive from http://justsolve.archiveteam.org/wiki/LZX.
- `xpk*.library` and `xpk_compress_files.txt`: Files extracted from `xpk_compress.lzx` and a listing of its contents, used as expected data. The `xpk*.library` files are Amiga XPK compression libraries by their respective authors.
- `dirs-files.lzx`: Lzx archive with directories and files.
- `unlzx.exe` and `unlzx_readme.txt`: PPCunlzx for Windows 95 by ALeX Kazik from Aminet, a recompiled version of unlzx. It's not used by the unit tests. Neither the binary nor the original unlzx.c source states a license.
