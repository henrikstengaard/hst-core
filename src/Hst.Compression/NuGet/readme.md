# Hst Compression

Hst Compression is a library for reading and extracting compression file formats.

Features:
- Read and extract lha archives with methods -lh0-, -lh1-, -lh4- to -lh7-, -lhx-, -lk7-, -lzs-, -lz4-, -lz5-, -pm0-, -pm1- and -pm2-.
- Read and extract lzx archives.

Creating lha archives and extracting -lh2- and -lh3- methods is provided by the separate package Hst.Compression.Lha, which is distributed under the LHa for UNIX redistribution terms.
