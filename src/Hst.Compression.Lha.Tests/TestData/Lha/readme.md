# Lhasa test archives

Test archives copied from the test suite of Lhasa, https://github.com/fragglet/lhasa (test/archives).
Files are renamed as `<directory>_<file>`, e.g. `unlha32/lh2.lzh` is renamed to `unlha32_lh2.lzh`.
